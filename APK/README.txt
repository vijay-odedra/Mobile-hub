STOCKLY - ANDROID MOBILE APPLICATION (APK)
===========================================

Application Name: Stockly
Package: com.stockly.app
File: Stockly.apk (13 MB)

INSTALLATION INSTRUCTIONS FOR ANDROID:
1. Transfer "Stockly.apk" to your Android mobile device using a USB cable, WhatsApp, or cloud storage.
2. Open your mobile File Manager and tap on "Stockly.apk".
3. When prompted, select "Settings" -> "Allow from this source" / "Install unknown apps".
4. Tap "Install".
5. Launch Stockly on your mobile device!
6. All inventory products, billing records, and repairs synchronize in real-time with your Stockly Desktop App and Firebase Firestore Cloud Database.
